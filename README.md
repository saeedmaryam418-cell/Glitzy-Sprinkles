# 🍰 Glitzy Sprinkles

**Glitzy Sprinkles** is a modern and elegant bakery website designed to showcase handcrafted cakes, cupcakes, pastries, cookies, and other sweet treats. The project focuses on creating a visually appealing and user-friendly bakery experience using **HTML5 and CSS3**, with carefully designed layouts, typography, animations, and interactive visual elements.

The website presents Glitzy Sprinkles as a complete bakery brand, allowing visitors to explore the menu, view featured creations, provide custom order details, and get in touch with the bakery.

---

## ✨ Features

### 🏠 Home Page

* Attractive hero section with bakery branding and opening hours
* Best Sellers section featuring popular products
* About Us section introducing the bakery
* "Why Choose Us" section highlighting the bakery's qualities
* Visit Our Bakery section with an animated image carousel
* Navigation and footer with quick links and bakery information

### 🛍️ Shop Page

* Organized product collections
* Separate sections for cakes, cupcakes, pastries, cookies, and other sweet treats
* Product cards containing:

  * Product images
  * Product names

  * Prices
  * Add to Cart buttons

### 🎂 Our Creations

* Dedicated showcase for the bakery's handcrafted creations
* Large visual sections for cakes, cupcakes, pastries, and cookies

* Celebration-focused content
* Call-to-action section linking visitors to the menu

### 📝 Order Details

* Customer information form
* Order details section
* Delivery address and preferred date/time

### 📩 Contact Page

* Bakery contact information

## 🎨 Design & Styling

The website uses a soft, elegant bakery-inspired visual style with a combination of **blush pink, cream, white, and neutral tones**.

The design includes:

* Custom color variables using CSS
* Playfair Display and Poppins typography
* Rounded product and content cards
* Box shadows for depth
* Hover effects
* Smooth transitions
* Hero sections with background imagery
* Grid and flexbox layouts
* Decorative dividers and visual elements
* CSS animations

The CSS also includes a **CSS-only bakery image carousel**, created without JavaScript, using animations and 3D perspective effects.

---

## 🛠️ Technologies Used

* **HTML5** — Used to structure the website and create the different pages and forms.
* **CSS3** — Used for styling, layouts, responsive design, transitions, hover effects, and animations.
* **Google Fonts** — Playfair Display and Poppins are used for the website typography.

## 🌸 Project Highlights

One of the main goals of Glitzy Sprinkles was to create more than a simple bakery webpage. The project was designed as a complete multi-page bakery experience with consistent branding and navigation throughout the website.

## The Shop page organizes products into different categories, while the Creations page focuses on visually presenting the bakery's work. The Order Details page provides structured fields for customer, delivery, customization, and payment preferences.

## 📚 What I Learned

Through this project, I strengthened my understanding of **HTML and CSS** by developing a complete multi-page website from scratch. I learned how to organize website content into reusable sections, create structured forms, design product cards and responsive layouts, and maintain consistent styling across multiple pages.

I also gained practical experience with **CSS transitions, hover effects, animations, Flexbox, Grid, typography, and visual hierarchy**. Creating the CSS-only bakery carousel helped me understand how animations and positioning can be combined to create interactive visual effects without JavaScript.
